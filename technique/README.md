# Technique

Classes techniques reutilisables par les controllers et modeles.

- `Collection.php` : collection generique d'objets.
- `JeuEnregistrement.php` : curseur simplifie au-dessus de PDO.
- `Passerelle.php` : adaptation des lignes SQL en objets metier.
- `PDF.php` : wrapper local de FPDF, avec conversion UTF-8 vers ISO-8859-1.
