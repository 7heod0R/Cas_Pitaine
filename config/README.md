# Configuration

Ce dossier contient la configuration technique de l'application.

## Fichier

- `Database.php` : crée la connexion PDO singleton vers la base MySQL `dbBat`.

## Reglages XAMPP

Par defaut : `localhost`, utilisateur `root`, mot de passe vide. Modifiez les constantes dans `Database.php` si votre installation MySQL utilise d'autres identifiants.
